## What this pass delivers

1. `app/` Starlette service over the P1 store: every live `/api/triage/*` route the
   Android app + web UI use, same paths, same methods, same 2xx/400/404 shapes, plus
   the claim surface (below). The store stays HTTP-free.
2. `tests/test_api.py` — every route against a throwaway DB via raw ASGI (no listener),
   including claim lifecycle; wired into `tests/run_all.py`.
3. A cutover runbook (backup, rollback tags, COPY-app/ trap, verify-routes-mounted,
   tap-E2E, Android+web checks). Deployment material is not part of this repo, and
   there is no deploy in this pass.
4. `Dockerfile` (port 3038, HELM_* env), mirroring the live gateway's shape.

## NEW: claims (the executor-agnostic surface, per product steer + spike)

- POST /api/triage/threads/{id}/claims {executor_id, runtime, caps{timeout_s,
  max_budget_usd, max_turns, model}} → 201 {claim_id, lease_deadline} or 409 if an
  unexpired claim exists. Claim rows: thread_id, executor_id, runtime, caps, claimed_at,
  deadline, released_at, result_at.
- Claims are how "working" threads get executed: pending-dispatch items become
  claimable; mark_dispatched(mode="start") and a claim are mutually consistent (a claim
  supersedes the legacy attempt counter; both recorded).
- POST /api/triage/threads/{id}/claims/{claim_id}/result → validates the claim is live,
  posts the result THROUGH post_result (so every gate applies), records executor
  identity + cost fields (runtime, model, models_billed, cost_usd, cost_basis,
  duration_s, num_turns, capped, timed_out, permission_denials) as event data.
- Expired claims (deadline passed, no result): re-claimable; the expiry is visible in
  pending-dispatch with a distinct reason word.
- GET /api/triage/claims?state=live|expired → for the watchdog (separate host).

## Rules

- Live 400/404 detail strings that producers currently parse get carried over verbatim
  where the P1 store's Rejection messages don't already cover them (store wins on
  overlap — its messages are the self-fixing contract).
- No network in tests. No secrets. python3. Every handler: parse → one store call → JSON.
- Bearer auth identical to live (Authorization: Bearer, env HELM_APP_TOKEN; /api/meta
  unauthenticated).
